# Nginx Learning

Учебный проект по базовой конфигурации Nginx, маршрутизации и работе веб-страниц
через reverse proxy.

В репозитории находятся HTML, CSS, JavaScript и конфигурационные примеры. Веб-
страницы используются как демонстрационные upstream-ресурсы, а отдельные
сценарии показывают обработку маршрутов и служебных location.

## Запуск

Для просмотра статических страниц можно открыть `index.html` в браузере. Для
проверки Nginx установите Nginx и подключите конфигурацию проекта:

```bash
nginx -t -c <путь-к-конфигурации>
nginx -c <путь-к-конфигурации>
```

## Содержимое

- `index.html` — демонстрационная страница;
- `styles.css` — оформление;
- `script.js` — интерактивные элементы;
- конфигурационные материалы Nginx.
